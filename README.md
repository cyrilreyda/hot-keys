# Гарячі клавіші

Гра для уроків інформатики (2–7 класи): діти вчать клавіатурні скорочення на намальованому робочому столі. Правильна комбінація справді змінює документ: текст копіюється, скасовується, стає жирним. Стиль, нейрончики й бейджі такі самі, як у «Клавіатурних перегонах» з [Лабораторії](https://tkc-teacher.github.io/cikavo/labs/index.html).

Інструкція для вчителів: [guide/index.html](guide/index.html). Вона відкривається й із гри: кнопка «Як грати», блок «Для вчителя».

Гра — це один файл `index.html`, без сервера й збирання. Прогрес зберігається в браузері учня (`localStorage`, ключ `hot-keys-v1`) під його ім'ям.

## Що є в прототипі

- Тема «Текст», етапи 1 і 2: 20 карток-скорочень. Етап 3 і теми «Файли», «Браузер», «Windows» показані як «скоро».
- Режими: «Знайомство» (кожна комбінація по черзі з підказкою) і «Тренування» (10 завдань упереміш, слабші картки випадають частіше).
- Картки ростуть від бронзи до золота: 3 правильні відповіді без підказки, потім 8 за 2 дні, 15 за 3 дні.
- 6 місій: ланцюжки завдань на час, медалі за помилки, підказки й швидкість.
- За нейрончики відкриваються шпалери, аксесуари робота-помічника, теми вікон і місії.
- Робот пояснює помилку: що зробила натиснута комбінація або якого модифікатора бракує.
- Посилання: учень надсилає результат місії або свої досягнення; вчитель дає посилання на етап (`#e=1`) чи місію (`#m=3`). Місія за посиланням відкривається навіть без нейрончиків. Усі посилання є у вікні «Як грати».

## Запуск

Відкрити `index.html` у браузері або опублікувати репозиторій через GitHub Pages. Для локальної перевірки:

```powershell
python -m http.server 8765
```

## Як додати завдання

Картки й місії описані даними на початку скрипту (`CARDS`, `MISSIONS`). У тексті завдання `|` позначає курсор, а `[…]` виділення. Поле `before` задає стан до «випадкової» дії для Ctrl+Z, `after` задає скасовану дію для Ctrl+Y. Крок місії без `text` продовжує документ попереднього кроку.

## Обмеження

- Браузер не віддає сторінці Win+…, Alt+Tab, Ctrl+W, Ctrl+T, Ctrl+N. Для тем «Windows» і «Браузер» такі комбінації доведеться збирати кліками на екранній клавіатурі.
- Нейрончики не спільні з «Клавіатурними перегонами»: у кожної гри свій баланс. Спільний баланс можливий, лише якщо обидві гри лежать на одному домені.
- Економіку нейрончиків ще не перевіряли на справжньому уроці. Перша місія на золото одразу відкриває кілька нагород.
