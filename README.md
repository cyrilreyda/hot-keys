# Гарячі клавіші

Гра для уроків інформатики (2–7 класи): діти вчать клавіатурні скорочення на намальованому робочому столі. Правильна комбінація справді змінює те, що на екрані: текст копіюється, файл перейменовується, відкривається нова вкладка, вікна згортаються. Стиль, нейрончики й бейджі такі самі, як у «Клавіатурних перегонах» з [Лабораторії](https://tkc-teacher.github.io/cikavo/labs/index.html).

Інструкція для вчителів: [guide/index.html](guide/index.html). Вона відкривається й із гри: кнопка «Як грати», блок «Для вчителя».

Гра — це один файл `index.html`, без сервера й збирання. Прогрес зберігається в браузері учня (`localStorage`, ключ `hot-keys-v1`) під його ім'ям.

## Що є в прототипі

- Чотири теми, у кожній етапи 1 і 2 (етап 3 показаний як «скоро»):
  - «Текст» — мінідокумент, 20 карток;
  - «Файли» — Провідник із папками, кошиком і буфером обміну, 15 карток;
  - «Браузер» — вкладки, масштаб, пошук на сторінці, рядок адреси, закладки, 14 карток;
  - «Windows» — вікна, меню «Пуск», блокування, знімок екрана, диспетчер завдань, 13 карток.
- Режими: «Знайомство» (кожна комбінація по черзі з підказкою) і «Тренування» (10 завдань упереміш, слабші картки випадають частіше).
- Картки ростуть від бронзи до золота: 3 правильні відповіді без підказки, потім 8 за 2 дні, 15 за 3 дні.
- 18 місій, по 4–6 на тему: ланцюжки завдань на час, медалі за помилки, підказки й швидкість. У деяких кроках треба надрукувати назву папки, слово для пошуку чи адресу сайту.
- Комбінації, які забирає браузер або Windows (Win+…, Alt+Tab, Ctrl+T, Ctrl+W тощо), учні збирають мишкою на екранній клавіатурі.
- За нейрончики відкриваються шпалери, аксесуари робота-помічника, теми вікон і місії.
- Робот пояснює помилку: що зробила натиснута комбінація або якого модифікатора бракує.
- Посилання: учень надсилає результат місії або свої досягнення; вчитель дає посилання на етап (`#e=files:1`) чи місію (`#m=9`). Місія за посиланням відкривається навіть без нейрончиків. Усі посилання є у вікні «Як грати».

## Запуск

Відкрити `index.html` у браузері або опублікувати репозиторій через GitHub Pages. Для локальної перевірки:

```powershell
python -m http.server 8765
```

## Як додати завдання

Картки й місії описані даними в скрипті (`CARDS`, `MISSIONS`, теми — `TOPICS`). Кожна тема має свою програму в `APPS`: `make` будує стан із завдання, `apply` виконує комбінацію, `render` малює.

- «Текст»: у `text` знак `|` позначає курсор, а `[…]` виділення; `before` — стан до «випадкової» дії для Ctrl+Z, `after` — скасована дія для Ctrl+Y.
- «Файли»: `path` — відкрита папка, `focus` — вибраний елемент, `sel` — виділення, `clip` — буфер обміну.
- «Браузер»: `tabs` — вкладки (`'school'` або `'school>wiki'`, якщо є куди повертатися), `active`, `zoom`, `err` — сторінка не завантажилась.
- «Windows»: `wins` — відкриті вікна (останнє активне), `locked`, `hang` — програма не відповідає, `max`.
- Для всіх: `pre` — комбінації, виконані до початку завдання; `screen:true` — збирати мишкою; `goal` — завдання з друком, яке зараховується за станом.

Крок місії без поля, що задає стан (`text`, `path`, `tabs` або `wins`), продовжує стан попереднього кроку.

## Подяка

Оформлення, нейрончики, бейджі й будова профілю взяті з гри «Клавіатурні перегони» з [Лабораторії](https://tkc-teacher.github.io/cikavo/labs/index.html), з дозволу її автора.

## Обмеження

- Комбінації, які збирають мишкою, на справжній клавіатурі виконає сам браузер чи Windows: Ctrl+W закриє вкладку, Win+D згорне браузер. Гра попереджає про це в кожному такому завданні.
- Нейрончики не спільні з «Клавіатурними перегонами»: у кожної гри свій баланс. Спільний баланс можливий, лише якщо обидві гри лежать на одному домені.
- Економіку нейрончиків ще не перевіряли на справжньому уроці. Перша місія на золото одразу відкриває кілька нагород.
