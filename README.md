# Гарячі клавіші

Гра для уроків інформатики (2–7 класи): діти вчать клавіатурні скорочення на намальованому робочому столі. Правильна комбінація справді змінює те, що на екрані: текст копіюється, файл перейменовується, відкривається нова вкладка, вікна згортаються. Стиль, нейрончики й бейджі такі самі, як у «Клавіатурних перегонах» з [Лабораторії](https://tkc-teacher.github.io/cikavo/labs/index.html).

Інструкція для вчителів: [guide/index.html](guide/index.html). Вона відкривається й із гри: кнопка «Як грати», блок «Для вчителя».

Гра — це один файл `index.html`, без сервера й збирання. Прогрес зберігається в браузері учня (`localStorage`, ключ `hot-keys-v1`) під його ім'ям.

## Що є в прототипі

- Чотири теми (етапи 3 «Файлів» і «Браузера» показані як «скоро»):
  - «Текст» — мінідокумент, етапи 1–3, 23 картки;
  - «Файли» — Провідник із папками, кошиком і буфером обміну, етапи 1–2, 15 карток;
  - «Браузер» — вкладки, масштаб, пошук на сторінці, рядок адреси, закладки, етапи 1–2, 14 карток;
  - «Windows» — вікна, меню «Пуск», блокування, знімки екрана, мова Alt + Shift, диспетчер завдань, етапи 1–3, 16 карток.
- Режими: «Знайомство» (кожна комбінація по черзі з підказкою) і «Тренування» (10 завдань упереміш, слабші картки випадають частіше).
- Картки ростуть від бронзи до золота: 3 правильні відповіді без підказки, потім 8 за 2 дні, 15 за 3 дні.
- 20 місій, по 4–7 на тему: ланцюжки завдань на час, медалі за помилки, підказки й швидкість. У деяких кроках треба надрукувати назву папки, слово для пошуку чи адресу сайту.
- Комбінації, які забирає браузер або Windows (Win+…, Alt+Tab, Ctrl+T, Ctrl+W тощо), учні збирають мишкою на екранній клавіатурі. PrtSc і Num Lock можна і натиснути, і клацнути; цифровий блок з'являється на екранній клавіатурі лише в завданнях про Num Lock.
- За нейрончики відкриваються шпалери, аксесуари робота-помічника, теми вікон і місії.
- Робот пояснює помилку: що зробила натиснута комбінація або якого модифікатора бракує.
- Клік по роботу — жарт: по тулубу він хіхікає від лоскоту, а якщо лоскотати далі — сердиться й кличе вчителя; по голові відповідає за аксесуаром (кепка, навушники, окуляри, бантик, шолом, корона, антена).
- 17 наліпок за досягнення (див. нижче) — останній блок головної сторінки.
- Посилання: учень надсилає результат місії або свої досягнення; вчитель дає посилання на етап (`#e=files:1`) чи місію (`#m=9`). Місія за посиланням відкривається навіть без нейрончиків. Усі посилання є у вікні «Як грати».

## Наліпки

Наліпки видно останнім блоком під вкладками меню: отримані кольорові, решта сірі. Усі збираються поступово: поки наліпку не отримано, її іконка знизу вгору заповнюється кольором на стільки, скільки вже зібрано, а під назвою видно, наприклад, «12 з 30». Клацання по наліпці підказує, за що її дають. Нові наліпки гра показує після раунду, а заслужені поза раундом (вихід посеред раунду, прогрес гравця, зібраний до появи наліпок) — у словах робота в меню.

| Наліпка | За що |
|---|---|
| 🐣 Початок | перше знайомство, тренування чи місія до кінця |
| 🌡️ Гаряча сесія | 30 завдань поспіль без помилок і підказок (серія переходить з раунду в раунд, у прогресі — рекорд) |
| ⚡ Блискавка | 50 завдань швидше ніж за 2,5 с без помилок і підказки |
| 📅 Щодня потроху | гра в 5 різні дні |
| 🃏 Колекціонер | бронза на 30 картках |
| 🥇 Золотий фонд | 5 карток на золоті |
| 📝 Знавець тексту | срібло на 10 картках теми «Текст» |
| 📁 Знавець файлів | срібло на 7 картках теми «Файли» |
| 🌐 Знавець браузера | срібло на 7 картках теми «Браузер» |
| 🖥️ Знавець Windows | срібло на 8 картках теми «Windows» |
| 🏆 Агент місій | 10 різних місій |
| 📜 🗂️ 🧭 ⚙️ Герой тексту, файлів, браузера, Windows | усі місії теми |
| 👑 Золоті місії | золото в 5 місіях |
| 🧠 Розумник | 1000 нейрончиків |

Знайомство рахується лише для «Початку» й днів гри: там підказка є завжди. Умови — `STICKERS` (`count` і `need`), лічильники — `ach` у профілі гравця. Отримані наліпки потрапляють і в посилання на досягнення.

Коли пройдено останню місію теми, екран результату й робот повідомляють, що всі місії теми пройдено, а на вкладці «Місії» над місіями цієї теми лишається така сама плашка.

## Запуск

Відкрити `index.html` у браузері або опублікувати репозиторій через GitHub Pages. Для локальної перевірки:

```powershell
python -m http.server 8765
```

## Без інтернету

- Сайт: достатньо один раз відкрити https://cyrilreyda.github.io/hot-keys/ з інтернетом. Службовий скрипт (`sw.js`) збереже гру й інструкцію, і далі та сама адреса відкривається без мережі. У Chrome гру можна встановити як застосунок (значок у рядку адреси або меню «Встановити»).
- Файл: завантажити репозиторій (Code → Download ZIP), розпакувати й відкрити `index.html`. Сервер не потрібен. Посилання на результат у такому разі ведуть на опубліковану адресу.
- Шрифти лежать у `fonts/` (ліцензія SIL OFL 1.1), тому гра без інтернету виглядає так само.
- Без інтернету не працюють посилання «← Інформатика в 131-й» на каталог ігор і відкриття посилань на результат (його можна скопіювати й надіслати пізніше).
- Прогрес у браузері окремий для сайту й для файлу. Якщо браузер очищує дані після сеансу, зникає і збережена офлайн-копія сайту, і прогрес.
- Після змін у грі бажано змінити `CACHE` у `sw.js` (наприклад, `hot-keys-v2`), щоб прибрати старі файли з кешу. Свіжу версію з інтернетом учні отримують і без цього.

## Як додати завдання

Картки й місії описані даними в скрипті (`CARDS`, `MISSIONS`, теми — `TOPICS`). Кожна тема має свою програму в `APPS`: `make` будує стан із завдання, `apply` виконує комбінацію, `render` малює.

- «Текст»: у `text` знак `|` позначає курсор, а `[…]` виділення; `before` — стан до «випадкової» дії для Ctrl+Z, `after` — скасована дія для Ctrl+Y.
- «Файли»: `path` — відкрита папка, `focus` — вибраний елемент, `sel` — виділення, `clip` — буфер обміну.
- «Браузер»: `tabs` — вкладки (`'school'` або `'school>wiki'`, якщо є куди повертатися), `active`, `zoom`, `err` — сторінка не завантажилась.
- «Windows»: `wins` — відкриті вікна (останнє активне), `locked`, `hang` — програма не відповідає, `max`.
- Для всіх: `pre` — комбінації, виконані до початку завдання; `screen:true` — збирати мишкою; `both:true` — натиснути або клацнути; `goal` — завдання з друком, яке зараховується за станом.

Крок місії без поля, що задає стан (`text`, `path`, `tabs` або `wins`), продовжує стан попереднього кроку.

## Подяка

Оформлення, нейрончики, бейджі й будова профілю взяті з гри «Клавіатурні перегони» з [Лабораторії](https://tkc-teacher.github.io/cikavo/labs/index.html), з дозволу її автора.

## Обмеження

- Комбінації, які збирають мишкою, на справжній клавіатурі виконає сам браузер чи Windows: Ctrl+W закриє вкладку, Win+D згорне браузер. Гра попереджає про це в кожному такому завданні.
- Нейрончики не спільні з «Клавіатурними перегонами»: у кожної гри свій баланс. Спільний баланс можливий, лише якщо обидві гри лежать на одному домені.
- Економіку нейрончиків ще не перевіряли на справжньому уроці. Перша місія на золото одразу відкриває кілька нагород.
